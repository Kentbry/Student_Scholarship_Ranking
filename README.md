Student Scholarship Ranking System

Project Description
The Student Scholarship Ranking System is a Java desktop application developed using NetBeans. It helps manage student applicants, evaluate their scores, identify the highest-ranked applicants, and award scholarships.

Features
Register student applicants.
Validate Student ID, name, and score.
Prevent duplicate Student IDs.
Display all registered applicants.
Search applicants using Student ID.
Identify the highest-ranked applicant.
Award scholarships to applicants with the highest score.
Support multiple applicants with the same highest score.

Technologies Used
Java
Java Swing
NetBeans IDE
Git and GitHub

Data Structure and Algorithm
Fixed-size arrays for storing applicant information.
Linear Search for finding applicants.
Linear comparison for identifying the highest score.
